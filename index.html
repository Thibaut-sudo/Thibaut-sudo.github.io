En production Plateforme web

Belgian Slot Club

Plateforme web des clubs de slot racing belges, consultable en ligne sur belgianslotclub.com.

Contexte

Une même application pour trois clubs (Slot 4000, SRCS, Rallyes Slot) : résultats, championnats, calendrier commun, forum et marketplace.

Architecture & points techniques

Java 25 et Spring Boot 3.5 (Thymeleaf, Spring Security, JPA, Flyway), PostgreSQL en production, import des résultats circuit depuis Excel (Apache POI) et tests JUnit. Déploiement automatisé via GitHub Actions sur un Raspberry Pi, derrière nginx, systemd et Cloudflare, avec health check et page de maintenance.

Défis résolus

Faire cohabiter plusieurs clubs et un calendrier interopérable (.ics, Google Agenda, Apple Calendar), fiabiliser l’import Excel des résultats, et maintenir une mise en production réelle (CI/CD, Cloudflare, supervision).

Java 25 Spring Boot 3.5 Spring Security Thymeleaf JPA Flyway PostgreSQL Apache POI JUnit GitHub Actions nginx Cloudflare

Application métier Full-stack

Artisan Pro

Application métier pour un atelier alimentaire (traiteur / cuisine centrale) : recettes, production, stocks, achats et facturation.

Contexte

Pilotage du quotidien de l’atelier : recettes et marges, planning de production, stocks et traçabilité (lots, réceptions, inventaires), achats, livraisons, devis, notes de crédit et facturation.

Architecture & points techniques

API NestJS typée (Prisma / PostgreSQL), authentification par jeton signé, mots de passe hachés avec scrypt, droits par rôle appliqués côté serveur. Interface React / Vite branchée écran par écran sur l’API, PostgreSQL via Docker, tests E2E Jest (authentification et droits par rôle).

Défis résolus

Recalcul automatique des marges à chaque variation de prix d’achat, avec alertes et prix de vente cible. Modèles Prisma dédiés pour les lots, réceptions, inventaires, devis et notes de crédit.

NestJS TypeScript Prisma PostgreSQL React Vite Docker Jest

iOS / Android Application mobile

BaladeVélo

Application mobile qui génère une boucle à vélo selon le point de départ, la distance, le type de terrain et le dénivelé.

Contexte

App Expo (iPhone et Android) : départ par GPS ou recherche, distance de 5 à 120 km, terrains route, mixte, gravel ou VTT, et prise en compte du dénivelé.

Architecture & points techniques

React Native, Expo et TypeScript. Les itinéraires sont calculés sur le réseau cyclable OpenStreetMap via OSRM, sans compte ni clé API.

Défis résolus

Affichage sur la carte, régénération d’un parcours, enregistrement local sur le téléphone, export GPX et ouverture dans Plans ou Google Maps.

React Native Expo TypeScript OpenStreetMap OSRM Géolocalisation GPX

macOS / Windows / Linux Application desktop

Générateur de QR codes

Outil desktop pour saisir un texte ou une URL, générer le QR code en local et l’enregistrer en PNG — sans service cloud.

Contexte

Application Electron packagée pour les trois bureaux : DMG sur macOS, installeur NSIS et version portable sur Windows, AppImage sur Linux.

Architecture & points techniques

Bridge sécurisé (preload) entre l’interface et le processus principal. Packaging multi-plateforme avec electron-builder. Toute la génération reste locale.

Défis résolus

Isoler correctement l’accès au système de fichiers via le preload, et livrer un installeur propre sur chaque système, sans dépendre d’un backend.

Electron Node.js qrcode electron-builder
